# GitHubに置くファイル

ZIPを解凍し、中の `index.html`、`hub.css`、`app.js`、`data.js`、`imajin/` フォルダーなどを、リポジトリの一番上に置いてください。ビルド、Javaのインストール、npmの実行は不要です。JavaScriptはブラウザーで動きます。画像は各店の掲載元を参照するため、インターネット接続が必要です。

## GitHub Pagesで表示する

1. 対象リポジトリへファイルを追加し、コミットします。
2. `Settings` → `Pages` を開きます。
3. `Source` を `Deploy from a branch` にします。
4. ファイルを置いたブランチ（通常 `main`）と `/(root)` を選び、`Save` を押します。
5. 公開後に表示されるURLを開きます。

手順の出典：[GitHub公式ドキュメント](https://docs.github.com/ja/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

通常のGitHub Pagesはインターネットへ一般公開されます。リポジトリを非公開にしてもサイト閲覧を家族だけに制限できるとは限りません。このZIPにはログイン認証機能はありません。家族内に留めるなら、ZIPを家族に渡して各端末で `index.html` を開く方法が使えます。
